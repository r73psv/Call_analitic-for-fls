# РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
## Интеллектуальная система речевой аналитики и контроля качества звонков («Fashion Look Studio» / «LIQ28»)
### (Версия 3.0 • GigaASR / Yandex SpeechKit / T-Bank VoiceKit • Сбер GigaChat Ultra + Repair + Verifier • 152-ФЗ РФ)

---

## 1. Назначение системы

Система предназначена для автоматизированного мониторинга, транскрибации, смыслового анализа, фактчекинга и аудита качества входящих и исходящих телефонных разговоров администраторов салонов красоты («Fashion Look Studio» и «LIQ28»).

### Ключевые возможности:
1. **100% охват звонков**: автоматический сбор входящих и исходящих звонков через МегаФон ВАТС (Push-вебхуки + Pull REST WCGP).
2. **Гибкая транскрибация речи (STT)**:
   - Поддержка трёх провайдеров распознавания: **GigaASR / GigaAM v3 (Cloud.ru)**, **Yandex SpeechKit** и **T-Bank VoiceKit**;
   - Разделение и смысловое восстановление ролей («Менеджер» и «Клиент»), в том числе для однострочных стенограмм и исходящих звонков;
   - Устойчивость к сетевым сбоям (автоматические ретраи с бэкоффом и очередь распознавания).
3. **Многоступенчатый смысловой анализ Сбер GigaChat Ultra + Repair + Verifier**:
   - Основная модель анализа по умолчанию — **`GigaChat:Ultra`** (также доступны `GigaChat:Max`, `GigaChat:Pro`, `GigaChat:Lite`);
   - **8 обязательных параметров резюме** (цель обращения, услуга, мастер, стоимость, дата и время, состоялась ли запись, причина при отказе, дальнейшие действия менеджера);
   - **Оценка администратора по 10 критериям аудита** с цитатами из стенограммы, вердиктом аудитора, блоком ошибок и рекомендациями;
   - **Авто-ремонт (Repair)** и **двухпроходный фактчекер (Verifier)**: проверка утверждений и цитат по стенограмме, защита от галлюцинаций и ложных штрафов, подтверждение синтез-полей (например, перенос записи к другому мастеру без изменения цены/времени);
   - **Классификация звонков (Классы A/B/C)** и распознавание ASR-искажений названия салона («лис 28», «от, а, 28», «лик 28» → «LIQ28»).
4. **Формирование списка «Next Steps» (Следующие шаги)**:
   - Автоматический чек-лист задач для администратора по итогам звонка, отдельная вкладка контроля открытых задач и всплывающие напоминания.
5. **Обезличенный экспорт отчётов (CSV и PDF, 152-ФЗ)**:
   - Кнопка **«Экспорт отчета»** в блоке сводной аналитики (`StatsGrid`) для скачивания обезличенных отчётов за период в CSV или PDF;
   - Экспорт реестра звонков из «Журнала звонков» (CSV UTF-8 BOM и PDF А4 альбомный) и паспорта отдельного звонка.
6. **Интеграция с ВКонтакте (уведомления + ежедневная сводка KPI)**:
   - Оперативные обезличенные карточки звонков с **обязательным блоком «Краткий пересказ диалога»** (`{short_summary}`);
   - **Ежедневная автоматическая выгрузка сводки KPI после 21:00** (звонки, пропущенные, записи по видам услуг и мастерам, оценки администраторов).
7. **Строгое соответствие 152-ФЗ РФ и отказоустойчивость**:
   - Маскирование телефонных номеров и персональных данных во всех отчётах и сообщениях VK;
   - Электронный журнал учёта согласий на аудиозапись и обработку речи;
   - Шифрование хранилища (AES-256-GCM), пакетная синхронизация с S3 Timeweb Cloud с ретраями и сохранение очереди массового анализа при перезапуске сервера.

## 2. Ролевая модель и разграничение прав доступа (RBAC)

В системе реализованы 4 уровня доступа:

| Роль | Телефоны клиентов | Стенограмма разговора | Next Steps и экспорт | Системные настройки |
|---|---|---|---|---|
| **Администратор (Admin)** | Полный номер телефона | Дословная стенограмма | Формирование шагов, экспорт аналитики и реестров PDF/CSV | Полный доступ (токены АТС, STT, GigaChat, VK, YClients, S3, пароли) |
| **Управляющий (Manager)** | Маскирован: `+7(***)***-45-89` | Дословная стенограмма | Генерация Next Steps, экспорт PDF/CSV, выгрузка сводки в VK | Просмотр системных параметров (только чтение) |
| **Оператор (Operator)** | Маскирован: `+7(***)***-45-89` | Обезличенный диалог | Выполнение чек-листа Next Steps | Нет доступа |
| **Наблюдатель (Viewer)** | Маскирован: `+7(***)***-45-89` | Только резюме (152-ФЗ) | Просмотр журнала и аналитики | Нет доступа |

### Авторизация и смена пользователя
- Для входа в систему нажмите кнопку **«Войти по паролю»** в шапке приложения.
- Каждому пользователю доступна самостоятельная смена пароля через иконку ключа в верхнем бейдже.
- Сессия защищена токеном авторизации с фиксацией действий в журнале аудита.

## 3. Журнал звонков и панель фильтрации (`CallList`)

В левой части рабочего пространства расположен журнал звонков с панелью фильтров:

1. **Фильтрация по дате**: быстрые пресеты («Все», «Сегодня», «Вчера», «7 дней», «30 дней», «Этот месяц») и выбор точного диапазона дат с учётом местного часового пояса салона (`Europe/Samara`, UTC+4).
2. **Фильтрация по оператору**: выпадающий список дежурных администраторов с количеством обработанных вызовов.
3. **Фильтрация по оценке ИИ**: «Отличные (8–10)», «Средние (5–7)», «Низкие (1–4)».
4. **Фильтрация по тональности**: Позитивная, Нейтральная, Негативная / Спор.
5. **Быстрые чипы-пресеты**: «Претензии/Споры», «Запись подтверждена», «Отказы», «Низкий балл (<5)», «Высокий балл (8+)», «Пропущенные».

### Массовый анализ и устойчивость к перезапускам
- При запуске массового переанализа очередь звонков сохраняется в хранилище (какие звонки уже обработаны, а какие ожидают).
- Если сервер перезапускается во время массового прогона, обработка автоматически продолжается с места остановки, не начиная очередь заново.

## 4. Карточка звонка, классы вызовов и аудит качества (`CallDetails`)

При выборе звонка открывается детальная карточка, прошедшая конвейер **STT → GigaChat Ultra → Repair → Verifier**:

### 1. 8 обязательных параметров резюме
1. **Цель обращения** (подстановка одного только приветствия салона вроде «Добрый день, салон ...» запрещена и автоматически помечается на проверку);
2. **Запрашиваемая услуга**;
3. **Предложенный / выбранный мастер** (с проверкой по справочнику мастеров из YClients и фильтром паразитных слов);
4. **Озвученная стоимость**;
5. **Предложенные / согласованные дата и время**;
6. **Состоялась ли запись** (включая подтверждение существующей записи и перенос к другому мастеру);
7. **Причина, если запись не состоялась**;
8. **Дальнейшие действия менеджера (Next Steps)**.

### 2. Краткий пересказ и регламентное резюме
- **Суть обращения**: услуга, дата, время, мастер;
- **Краткий пересказ диалога** (2–4 связных предложения по фактическим репликам);
- **Вывод**: зафиксированный итог звонка;
- **Разбор работы менеджера**: оценка, конкретные ошибки (синхронизированные с критериями < 7) и рекомендации.

### 3. Оценка по 10 критериям аудита и правила классов звонков (A / B / C)
Оценка выставляется строго по применимым критериям из 10 (приветствие, выявление потребности, презентация услуги, работа с ценой, работа с графиком, работа с возражениями, допродажи, предложение альтернатив, закрытие на запись, завершение разговора):
- **Класс A (короткие / пустые вызовы, автоинформатор, «Алло — Алло», «Номер занят»)**: статус «Не применимо», оценка `null`, 0 критериев, без ошибок и без вердикта «требуется обучение». Короткие содержательные звонки с фактами записи (например, «мы пока предварительно забронировали с 12 до 2») защищены и оцениваются как полноценные (Класс C).
- **Класс B (частичный контакт / обрыв связи, справочный запрос о мастере «Можно Елену? — Её сейчас нет»)**: штраф по Критерию 9 («Закрытие на запись») и вердикт «требуется обучение» не применяются; фиксируются полезные следующие шаги (перезвонить клиенту).
- **Исходящие подтверждения записи и короткие обзвоны**:
  - Если администратор напоминает о существующей записи и клиент подтверждает визит («да, я буду», «подтверждаю»), Критерий 9 получает 9–10 баллов, а формулировки «бронь не оформлена» и «попытка закрытия отсутствовала» запрещены.
  - Если при коротком обзвоне клиент отказывается («сейчас не могу говорить», «увы, нет»), фиксируется статус «Консультация / отказ» без жёсткого штрафа за неоформленную бронь и с рекомендацией запланировать повторный обзвон.
- **Учёт ASR-искажений названия салона**: фонетически искажённые варианты названия бренда («лис 28», «от, а, 28», «лик 28») распознаются как корректное упоминание «LIQ28» — менеджер не штрафуется по Критерию 1.
- **Двухпроходный фактчекер (Verifier) и контроль цитат**: проверяет, что цитаты реально присутствуют в стенограмме и принадлежат нужному говорящему; составные факты (например, перенос записи к другому мастеру без изменения времени и цены) подтверждаются без ложных флагов; неподтверждённые данные помечаются статусом «требует проверки».

### 4. Ре-анализ и кнопка «Уточнить контекст у ИИ»
- Кнопка **«Переанализировать»** позволяет повторно запустить анализ с выбором модели (`GigaChat:Ultra`, `GigaChat:Max`, `GigaChat:Pro`, `GigaChat:Lite`) и при необходимости перетранскрибировать звонок выбранным STT-провайдером.
- Кнопка **«Уточнить контекст у ИИ»** позволяет задать любой вопрос по диалогу с получением ответа, подтверждённого прямыми цитатами из стенограммы, и сохранением истории уточнений.

## 5. Функция «Next Steps» (Следующие шаги для администратора)

В карточке звонка и в отдельной вкладке **«Задачи Next Steps»** формируется и отслеживается чек-лист задач по итогам диалога:
1. Нажмите **«Сформировать Next Steps (ИИ)»** (или используйте шаги, сформированные автоматически при анализе).
2. Отмечайте выполненные задачи кликом (статус сразу сохраняется в базе).
3. Используйте кнопки **«Копировать»**, **«Добавить задачу»**, **«Отметить все»** и **«Обновить ИИ»**.
4. При наличии открытых задач в правом нижнем углу экрана появляется всплывающее напоминание с возможностью перейти к задачам, отложить на 15 минут или свернуть в компактный бейдж.

## 6. Экспорт отчётов для внутренней отчётности (CSV и PDF, 152-ФЗ)

### 1. Кнопка «Экспорт отчета» в блоке аналитики (`StatsGrid`)
- Доступна администраторам и управляющим прямо в панели сводной статистики.
- Позволяет скачать **обезличенный отчёт за выбранный период** в формате **CSV** или **PDF** для подготовки внутренней отчётности (в строгом соответствии со 152-ФЗ: без открытых номеров телефонов и персональных данных клиентов).

### 2. Экспорт из «Журнала звонков» и карточки звонка
- **Таблица CSV (Microsoft Excel)**: UTF-8 BOM, разделитель `;`, защита от CSV-инъекций, блок сводных KPI и детальный реестр звонков по текущей выборке фильтров или всей базе.
- **Сводный реестр PDF (А4 альбомный)**: встроенные кириллические шрифты LiberationSans, карточки KPI, таблица вызовов с цветовой маркировкой и блок подписи управляющего.
- **Выгрузка отдельного звонка**: кнопки «PDF» и «CSV (152-ФЗ)» в карточке звонка.

## 7. Внешние интеграции

### 1. МегаФон ВАТС
- Гибридная работа по протоколам **Push (Webhooks)** (`/crm_integration.php`, `/api/calls/webhook`, `/api/vats/webhook`) и **Pull (REST WCGP)** (автоопрос каждые 5–15 минут и ручная выгрузка истории за период).

### 2. Распознавание речи (STT)
- Выбор активного провайдера в настройках администратора: **GigaASR / GigaAM v3 (Cloud.ru)**, **Yandex Cloud SpeechKit** или **T-Bank VoiceKit** (с изолированным выбором провайдера для ручной перетранскрибации).

### 3. ВКонтакте (VK) — уведомления и ежедневная сводка KPI
- **Оперативные уведомления по звонкам**: отправляются автоматически после анализа или вручную кнопкой **«ВКонтакте (152-ФЗ)»** в карточке звонка. В каждое отправляемое в VK сообщение **обязательно включается отдельный блок «📝 Краткий пересказ диалога»** (`{short_summary}`) — он добавляется автоматически даже при использовании собственного шаблона, а телефонные номера маскируются по 152-ФЗ.
- **Ежедневная сводка показателей после 21:00**: автоматическая выгрузка итогов дня по часовому поясу салона (по умолчанию `21:05`, настраивается в «Интеграциях» и «Администрировании»). Отчёт включает количество звонков (входящих/исходящих), число и долю пропущенных, конверсию и число записей, разбивку записей по видам услуг и мастерам, средние оценки администраторов. Доступны ручная кнопка **«Выгрузить итоги дня в VK»** и предпросмотр сводки; отчёт полностью обезличен по 152-ФЗ.

### 4. YClients CRM (строго режим «только чтение» мастеров)
- Используется исключительно для чтения актуального списка активных мастеров салона (авторизация по логину, паролю и `YCLIENTS_PARTNER_TOKEN`).
- Запись комментариев, задач или иных изменений в YClients полностью отключена. Список мастеров применяется для повышения точности извлечения имени мастера в анализе звонков.

### 5. S3 Timeweb Cloud (резервирование и архивация 152-ФЗ)
- Автоматическое шифрование базы данных (**AES-256-GCM**) и **пакетная синхронизация в S3** с дебаунсом (каждые 30–60 секунд или после накопления пакета изменений), ретраями с экспоненциальным бэкоффом (3 попытки: 5–15–30 сек) и гарантированным сохранением при завершении очереди массового анализа и перед остановкой сервера.
- Автоматическая архивация старых звонков старше `TTL_LOG_DAYS` в зашифрованный архив S3 по требованиям 152-ФЗ.
